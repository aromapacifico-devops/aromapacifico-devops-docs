# The farm is one reusable module with a certificate from a CSR

## Context

The 200 farms are not instantiated, and a reusable module of one farm must be delivered. In the cloud, a farm is an identity with no network of its own. Secrets must stay out of Terraform state.

## Options

A certificate generated by Terraform, a certificate from a CSR, or fleet provisioning alone.

## Decision

The module creates the thing, its group membership, a certificate from a CSR and the policy attachment. With a CSR, the private key stays on the device, while a certificate generated by Terraform would leave the private key in the state. The rollout of 200 farms repeats the module once per node, and each node is provisioned before shipment.

## Consequences

The state holds no key, and the module repeats with `for_each`. Each node generates its key pair and its request at provisioning, before shipment, so the installer handles no secret and no shared claim credential enters a node.
